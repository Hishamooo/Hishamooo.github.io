# CV Documents

Place the following PDF files in this directory:

- `cv-frontend.pdf` — Senior Frontend Developer CV (loaded as default from the navigation Download CV button)
- `cv-fullstack.pdf` — Senior Full-Stack Developer CV
- `cv-sdet.pdf` — Software Engineer in Test CV

After placing the files here, run `npm run build` to include them in the deployment.

The Download CV button in the navigation bar links to `/assets/documents/cv-frontend.pdf`.
Update the paths in `info.js` if you use different filenames.
